# Open Source First

Open source work is one of the fastest ways to build technical credibility with context.

## The common misconception

Many people think open source starts with advanced code only. In reality, useful contributions also include:

- Documentation improvements
- Test fixes
- Reproduction cases
- Accessibility refinements

## How HackUnion structures onboarding

We run lightweight contribution pathways where members start with scoped issues, then move toward deeper architecture work.

### Contributor ladder

1. Read and reproduce.
2. Make one safe improvement.
3. Open a pull request with context.
4. Respond to review and iterate.

## Career impact over time

Consistent open collaboration creates portfolio evidence that recruiters and teams can verify directly.

`signal = visible_work + consistency + collaboration_quality`

> The best resume line is often a merged contribution with clear discussion.
